AeroSaga: Temporal.io Autonomous Drone Mission Control

Project Overview

AeroSaga is an autonomous drone mission control project designed to organize and manage drone missions.

Objectives

- Organize drone mission workflows.
- Track mission status and progress.
- Explore workflow orchestration using Temporal.io.
- Learn backend development and system integration.

Technologies

- Java
- Spring Boot
- Temporal.io
- WebSocket

Development Status

This repository is being prepared for project development. Features will be added as implementation progresses.
